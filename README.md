# PreRun

이미 급등한 종목을 걸러 내고, 돌파 전에 보이는 신호만 점수로 보여 주는 한국 주식 화면입니다. 코스피·코스닥이 기본이고 미국 종목은 시장 필터로 볼 수 있습니다. 가격은 무료 공개 시세만 쓰고, 받지 못한 항목은 숫자를 만들지 않고 `데이터 없음`으로 둡니다.

## 후보

순위는 그래디언트 부스팅과, 구간 밖 로그손실이 더 낮을 때만 섞는 로지스틱 회귀입니다. 학습과 시험 경계의 앞뒤 10거래일은 비워서 10일 라벨이 시험 가격을 보지 못하게 합니다. 등확률 보정은 그 학습 구간을 다시 나눈 뒤, 학습에 안 쓴 점수에만 맞춥니다. 라벨은 10거래일 안에 손절(−5%와 −1×ATR 중 가까운 쪽)보다 목표(+7%와 +1.5×ATR 중 작은 쪽)가 먼저인지입니다. 카드의 큰 숫자는 보정 확률이고, 같은 칸에 그 점수대의 시험 적중률·건수·기준선을 적습니다. 보정 전 원점수는 카드에 나오지 않습니다. 코스피·코스닥이 60일선 아래이거나 변동성·원/달러가 스트레스면 기준을 올리고 후보는 최대 3개입니다. 스팩, 1000원 미만, 거래대금 하위 20%, 거래정지·경고 문구가 있는 종목은 뺍니다. 화면에 올린 후보는 로컬 장부에 남기고 이후 일봉으로 채점합니다.

모델에 더 넣는 시세는 코스피·나스닥 5일/20일 추세, 같은 시장 지수 대비 초과수익, 같은 업종 유니버스 대비 5일 초과수익, ATR 대비 변동 폭, 가격이 잠잠할 때의 거래량 비율입니다. 외국인·기관 수급은 최근 며칠만 공개되어 학습에 넣지 않고, 업종 화면의 대표 종목 수급으로만 보여 줍니다.

모델에 넣는 숫자는 아래입니다.

- 거래량은 20일 평균보다 늘었는데 5일 수익률은 -4%~+6%로 잠잠할 것
- 볼린저 밴드 폭이 최근 120일 중 하위 28%이고, 아직 상단을 안 넘었을 것
- 직전 52주 고점 -8%~-0.3%, 또는 20일 고점 -5%~-0.1%에 있을 것
- 5일선이 20일선 아래 2.5% 안에서 올라오고 있을 것
- 가격은 잠잠한데 OBV가 쌓여 있을 것
- RSI가 43~60이고 5일 전보다 2포인트 이상 회복했을 것

이미 오른 종목은 목록에서 뺍니다. 최근 1거래일 +8%, 3거래일 +12%, 5거래일 +15%, 20일선 이격 +8% 또는 RSI 72 이상, 52주 고점 돌파가 여기 해당합니다. 예상 구간이 지나도 +7%가 없거나 셋업이 깨지면 `타이밍 지남`으로 옮깁니다.

예상 시기는 시험 구간에서 같은 점수대였던 날들 중, 신호일 종가 대비 +7%에 처음 닿은 거래일을 1~3, 4~7, 8~15, 16~30일로 센 빈도입니다. 거래일 달력은 코드에 넣은 한국거래소·미국 휴장일을 쓰며 임시 휴장은 빠질 수 있습니다.

이 화면은 투자 조언이 아닙니다. 확률은 과거 빈도이고 예측은 빗나갈 수 있습니다.

## 로컬 실행

Python 3.11+ 과 Node.js 20+ 이 필요합니다.

```bash
pip install -r backend/requirements.txt
cd backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8765
```

다른 터미널에서:

```bash
cd frontend
npm install
npm run dev
```

브라우저에서 [http://127.0.0.1:43123](http://127.0.0.1:43123) 을 엽니다. 첫 계산은 종목 일봉을 받는 동안 수십 초 걸리고, 이후에는 `backend/data/cache` 를 씁니다.

뉴스 요약을 LLM으로 바꾸려면 `OPENAI_API_KEY` 를 넣습니다. 없으면 제목 단어로 호재·악재·중립을 가릅니다. 모델 이름은 `OPENAI_MODEL`(기본 `gpt-4o-mini`), 주소는 `OPENAI_BASE_URL` 입니다.

## 배포

루트의 `render.yaml` 은 Render Web Service 블루프린트입니다. Docker 이미지 하나가 FastAPI를 `127.0.0.1:8765` 에 띄우고, Next.js를 Render가 주는 `$PORT` 에 띄웁니다. 상태 확인 경로는 `/health` 입니다. `BACKEND_URL` 은 컨테이너 안에서 `http://127.0.0.1:8765` 입니다.

```bash
docker build -t prerun .
docker run --rm -p 10000:10000 -e PORT=10000 prerun
```

브라우저 주소는 `http://127.0.0.1:10000` 입니다. 네이버 금융과 야후 파이낸스로 나가는 HTTPS가 열려 있어야 합니다.
